# C17 单文件练习模板

适用于你已安装的工具链：`D:/c++/mingw64/bin/gcc.exe` 和 `gdb.exe`。

1. 解压到你想保存练习的位置，例如 `D:/vscode/c_practice`。
2. 用 VS Code 的“文件 → 打开文件夹”打开包含 `.vscode` 和 `main.c` 的文件夹。
3. 确认微软 C/C++ 扩展已经启用。
4. 打开 `main.c`，按 Ctrl+S 保存，再按 F5。
5. 点击下方“终端”，输入 `3 8` 并回车，结果应是 `11`。
6. 想观察变量，在第 9 行设置断点，按 F5 调试。

配置作用：tasks.json 指定 GCC 编译命令；launch.json 指定 GDB 和调试前的编译任务；settings.json 配置代码提示所用的编译器与 C17 标准。

这个模板每次只编译当前打开的一个 `.c` 文件。多个 `.c` 各自有 main，可以逐个打开练习；同一个程序拆成多个 `.c` 时需要另外配置多文件构建。

只有 `.c` 文件才按 C 学习。请在 C 源文件处于当前编辑标签时运行，不要停留在 JSON 或 README 标签上执行编译。

如果提示可执行文件 Permission denied，先停止上一次调试或运行。换了一台电脑或移动 MinGW 安装目录后，需要更新编译器和调试器的绝对路径。
